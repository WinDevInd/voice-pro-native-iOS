# Voice Pro UI

A small typed React component library styled with Tailwind CSS.

## Components

- `Button`: primary, secondary, and ghost variants
- `Input`: labels, helper text, and default, valid, or invalid states
- `Card`: a reusable content container
- `Badge`: neutral, success, warning, and danger variants

## Development

```bash
npm install
npm test
npm run typecheck
npm run build
```

Import the components and compiled stylesheet from the package:

```tsx
import { Button, Input } from "@voice-pro/ui";
import "@voice-pro/ui/styles.css";
```
